Start reuses the exact live identity. A workspace-wide mutex and file lock prevent a second queue instance from running another worker. Ownership binds PID, process birth, executable and command hash; shutdown preserves unrelated processes and checks owned survivors. Native launch explicitly disables handle inheritance and closes creation handles. The finished lifecycle test observed start/reuse, one windowless process, alternate-queue refusal, zero survivors after stop, and lease expiry.

`main/ownership.json` records the process identity. `main/status.json` distinguishes executing a case, waiting for source work, and stopped states; `stop_reason` records budget/lease/explicit termination. A waiting process is not continuous scientific progress. `main/model-budget.json` persists the authorized256-request ceiling and confirmed calls; reservations are conservative if an interrupted call has no returned receipt. Restarting never resets the request allowance or extends `main/lease.json`. The initial24h lease requires the computer awake and available networking. Reboot/login restart and automatic recovery after app/computer shutdown are not installed or claimed. Detachment from a terminated launcher is independently observed; persistence after a particular future root-chat final message must be checked afterward, not asserted in advance.

`main/queue` contains finite data contracts. `main/runs` preserves immutable requests, exact source spans, complete Jev receipts/model identities, Proofline packages, results, failures and parked deferrals. Single-message cases have no pointless joint assessment; `compare_sources:true` explicitly requests a genuine comparison. A declined preview batch is parked with the actual decision and does not stop other eligible work. No automatic retries turn a refusal into apparent approval.

`source-backlog.json` and immutable `backlog-builds` snapshots describe the bounded historical native intake. All full message projections and occurrence manifests are under `data/raw/background-projections`. Their bytes are exact UTF-8 encodings of stored message text, not native historical export bytes. Original source IDs, paths, hashes, roles, locators, timestamps and every matching duplicate occurrence remain attached. Oversized full messages are preserved pending, with no silent truncation. Prior exact module contact is distinguished from semantic completion and remains separately pending. Current generated Codex/tool/hook/task sources are excluded from this finite intake to prevent feedback; they remain within the larger project corpus.
