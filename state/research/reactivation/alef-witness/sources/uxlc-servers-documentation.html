Servers

The tanach.us site offers many features, but it draws on your device's bandwidth, memory, and computing power to do so.

A faster, lighter way to get Hebrew text from the site is to use one of the 4 servers. Depending on which server you call, it returns content formatted as XML, text, HTML, or ODT.

Each server requires a valid text citation!
The server parameters consist of a valid text citation, possibly followed by more parameters. Invalid citations produce errors. A valid citation for the servers takes one of three formats, defined on the Citation syntax page:
  • Complete book: b *
  • Single chapter:Verse range: b c:v1 - v2
  • Chapter:Verse range: b c1:v1 - c2:v2
The other 3 formats on the Citation syntax page don't work with the servers. Every server except Server.xml allows optional URL parameters after the citation to customize the display. View a served page in a browser, and you can save it as a file. The saved file gets a meaningful name, built from the abbreviated book name and the chapter/verse range.

Here's a simple example of a server call with no extra URL parameters:

https://tanach.us/Server.html?Deut26:5-9
This shows Deuteronomy 26:5-9 in HTML from the Server.html server. Enter this URL into a browser, and it downloads only the HTML file itself; the tanach.us site never has to load at all. The saved file will be named "Deut 26.5 - 9" . (Colons, ':', cause trouble in file names.) A wrong citation or parameter produces a clear error message. For example,
https://tanach.us/Server.html .
is wrong because it lacks a citation.

Click the links in the "Server" column to learn more about a particular server.

Server Purpose Parameters File extension
Server.xml A Unicode, UTF-8 text file with XML markup. Not HTML. None .xml
Server.txt A Unicode, UTF-8 text file, with no markup. layout, content. .txt
Server.html A hypertext (XHTML/CSS) document you can view in a browser. Many .html
Server.odt A standard Open Document (text) document. Many .odt

No server handles PDF files.

Checking that the servers are working.

Check the servers' status with this URL:
https://tanach.us/ServerTest
If the servers aren't working, contact the publisher to get them fixed.
