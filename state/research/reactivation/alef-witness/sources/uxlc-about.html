About

The Unicode/XML Leningrad Codex (UXLC) is a transcription of the Leningrad Codex (LC) into a modern computer format (Unicode, XML). The UXLC text is a fork of the Westminster Leningrad Codex [WLC 4.20, 25 Jan 2016] from the Groves Center. We update the text twice a year to better match the LC, using reader suggestions, through a formal, automated process; we have made more than a thousand changes since the fork in 2020. Books of the Torah can show source markings from the Documentary Hypothesis (DH). We keep the Hebrew text under version control, so derived work has a fixed reference point. See the Technical page for more.

You may view or copy all biblical Hebrew text, in any format, without restriction. (License)

You can reach the text quickly by typing a citation, i.e. Deut 26:5-9, into a text field, or by clicking through a series of links. Type in a citation, and the Book page comes up with the text you asked for. The Book page can show text in many formats and font sizes. You can highlight, copy, and paste Hebrew text into Unicode-compatible applications.

  • Each Book page carries links to external sites. The links match the book, chapter, and verse shown on the page, and include common translations. Two especially useful links go to sefaria.org:

    1. "Sefaria: Color image of Leningrad Codex" sends the browser to a high-quality color image of the Leningrad Codex page that holds the displayed UXLC text. These images are the basic reference for the UXLC; please tell the publisher of any difference between these images and the UXLC. See the LC images page for more.

    2. "Sefaria: Miqra according to the Masorah" links to a Tanach built from the Aleppo Codex, the Leningrad Codex, and related manuscripts, drawing on the full range of relevant Masoretic scholarship. It gives a valuable counterpoint to the Leningrad Codex-only Tanach shown here. When a transcription note 'c' or 't' appears in the text, the "Miqra according to the Masorah" link shows how the Leningrad Codex text compares with the Masorah in general.

  • The Hebrew text carries transcription notes, i.e. t. Hold the mouse pointer over a note symbol (i.e. t) to see a title describing the note's general type; click the note symbol to open a separate window with detailed information about that particular note.

  • To see details of selected Hebrew text (i.e. הַגָּ֔ן), highlight the text, hold down the SHIFT key, and click the highlighted area. The details include the Unicode character names (i.e. he patah gimel dagesh qamats zaqef-qatan final-nun), the hexadecimal values (05d4 05b7 05d2 05bc 05b8 0594 05df), and the HTML hexadecimal constants (&#x05d4; &#x05b7; &#x05d2; &#x05bc; &#x05b8; &#x0594; &#x05df;). This gives a quick way to identify Hebrew marks or insert short pieces of text into programs or HTML files.

  • Each file carries a standard Text Encoding Initiative (TEI) header describing the text. You can view the TEI header by clicking the Unicode/XML Leningrad Codex label at the top center of the Home or Book pages. The TEI header for each book lists attributed text corrections for that book.

  • The text comes in five formats:

    Format Purpose
    XML A Unicode, UTF-8 text file with XML markup. Good for machine processing and display. This is the root format for all the texts. Tanach.xml.zip zips up all the Tanach XML files.
    Text A Unicode, UTF-8 text file without markup. Readable by ordinary operating-system editors. Tanach.txt.zip zips up all the Tanach text files.
    HTML A browser-viewable hypertext (XHTML/CSS) document. You can pick from a wide range of formats by adding URL parameters to calls to the HTML server, i.e. https://tanach.us/Server.html?Deut26:5-9&content=Vowels&font=24&Brief=1&t1=Title with blanks&trailinglabel=1&lineheight=200. See HTML files to learn about the HTML server.
    ODT An Open Document (Text) standard document (ODT). Works with modern editors, especially the free  LibreOffice Writer. Handy for formatting to your own taste. Tanach.odt.zip zips up all the Tanach ODT files.
    PDF A portable document format document. Highly portable, with a consistent look (but not editable), using the free  Adobe Reader. Tanach.pdf.zip zips up all the Tanach PDF files.

    Each Book page has buttons to download the displayed text as XML, Text, HTML, or ODT. You can get PDF files of the displayed text from an ODT file in LibreOffice Writer, using "File/Export as/ Export to PDF".

 

The publisher is glad to help users and welcomes suggestions. Send proposed corrections to the Hebrew text to the publisher. Please see "How to suggest a text change".
