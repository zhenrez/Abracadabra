Error in call to Server.html: No parameters were given.

The Tanach Server.html requires a URL parameter specifying a text citation and, optionally, pairs of URL parameter names and values separated by an '&' sign. The citation parameter must have either the form Book Chapter:Verse - LastVerse, as in "http://tanach.us/Server.html?Gen2:3-5 or the form Book Chapter:Verse - LastChapter:LastVerse, as in "http://tanach.us/Server.html?Gen2:3-2:5. Note the '?' after the word Server.html. Book abbreviations are accepted and are case-insensitive. Blanks are ignored.

See the Servers.html page for additional information.
