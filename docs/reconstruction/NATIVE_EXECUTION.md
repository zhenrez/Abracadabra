## Exact interactions

This gives a precise reversal/rotation discriminator without selecting a privileged phase. All 1,088 cases n=1..32, k=-n..n pass, independently reproduced by Wolfram.

This is conditional on the actions occupying the stated value and position coordinates; it does not identify a particular native triad action.
