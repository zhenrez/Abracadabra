## 1. The object we are recovering is a score, not a seating chart

Assigning a figure to a note is only one small part of the task. The reconstruction must account for **what participates, what it does, what it responds to, when it enters, what it inherits, and how its contribution changes the whole**.

Your existing distinctions now have a unified purpose:

| Aspect of the score             | What the reconstruction must recover                                                                                                              |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Instrumentation and voices**  | Which kinds of entities and functions participate; whether an object represents a performer, part, ensemble, instruction, or organizing structure |
| **Notes and registers**         | Relative position, exact ratios, generational level, and the reference from which those positions are measured                                    |
| **Phrasing and transformation** | Generation, succession, separation, inheritance, opposition, restoration, and other changes—without treating them as interchangeable              |
| **Timing**                      | Entry, duration, order, overlap, recurrence, cessation, and conditions permitting an event                                                        |
| **Orchestration and authority** | Which relationships govern or coordinate others, and how authority changes without necessarily changing the underlying reference                  |
| **Performance history**         | What actually occurred, what was merely instructed or anticipated, and what accumulated across the sequence                                       |

These are questions for the existing **GEN / MEM / TIME / ADR / FUNC / TRN** register—not a replacement architecture.

A succession can change who carries a part without changing the foundational bass. A return can restore a nominal position while retaining a register change or accumulated residual. A command can appear in the score without having been executed in the witnessed performance.

**The distinctions we have already recovered are the beginnings of readable notation.**

## 2. Every source becomes a partial witness to the same reconstruction

Padgett might supply construction rules, a geometric view of an interval, an account of a transformation, or a representation of what an observer perceives. A genealogy might preserve sequence. A hierarchy might preserve orchestration or authority. A birth configuration might constrain an entrance. A narrative might preserve the consequences of a transition.

We should not demand that each source contain the entire composition—or describe its contribution in our preferred language.

Nor should we force every named figure to be a note. Some may correspond more naturally to a continuing function, a boundary condition, an instruction, a collective, or a transition. **Finding the correct representational level is part of finding the placement.**

The question for each source becomes:

> **Which passage of the score does this preserve, from which perspective, and what does it let us reconstruct that we could not reconstruct before?**

A disputed reading is then a competing transcription. We compare what each permits across the connected arrangement. A reading that fits the model gains model-relative support; calling it historically earlier still requires evidence about its transmission. Those are separate fields in the record, not separate research programs that interrupt each other.

## 3. Wins must become operational commitments

A result should not end with “interesting correspondence.” It must change what the next calculation can do.

That includes conditional results. **An unresolved pair of placements is not an empty result:** it is a two-candidate domain, with known shared properties and a specific remaining difference.

For the Padgett sequence, that means carrying forward the generative operations and their declared assumptions—not merely the counts. ## 4. Losses must alter the reconstruction

A failed comparison should end with a changed search space—not a warning followed by abandonment.

The useful outcome is something like:

> “This operation cannot represent succession at this level because it changes ancestry. It remains available as a generative operation elsewhere.”

Or:

> “This projection loses the remainder needed for closure. Keep the remainder; do not discard the source.”

Or:

> “These two candidates have the same abstract operator structure. Another cycle-count test cannot distinguish them; examine the ancestry relations on which they differ.”

That last example matters especially. **We should stop repeating tests that cannot discriminate the remaining alternatives.**

A loss can reveal a wrong placement, an omitted state variable, an incorrect witness combination, a mistaken operation, or a genuinely unsuccessful ingredient. We identify which, retain the consequence, and continue from the narrower problem.

We do not rescue a favored interpretation by silently changing its meaning. Equally, we do not discard an entire source because one proposed placement failed.

## 5. Testing serves the next reconstruction decision

The workflow should be:

\$$ \boxed{ \text{Recover the current passage} \\;\rightarrow\\; \text{identify its unresolved relationship} \\;\rightarrow\\; \text{perform a discriminating comparison} \\;\rightarrow\\; \text{retain the consequence} \\;\rightarrow\\; \text{extend the score}. } \$$

A test earns priority because its possible outcomes change an active decision. Additional validation can remain attached to a result without blocking every useful inference from it.

Likewise, outside research must answer a live question: recover an operation, resolve a reading, constrain an origin, explain a residual, or discriminate placements. A new theory does not automatically create a new branch of work.

**The unit of progress is a reconstructed relationship that can be used—not the number of sources collected or tests performed.**
