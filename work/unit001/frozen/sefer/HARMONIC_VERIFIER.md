# Conditional harmonic–phonetic verifier

`harmonic_verifier.py` implements the requested 3/7/12 structural hypothesis using NumPy, SciPy and NetworkX. Run `python work/ariadne-inverse/harmonic_verifier.py` for JSON demonstrations. Six focused tests are in `test_harmonic_verifier.py`.

The base is a disjoint set of three mother **slots**, seven double slots and twelve simple slots. Phonetic aliases are not necessarily disjoint: /s/ can denote the user's shin alternative or the simple samekh slot. Bipartite matching assigns each supplied observation to at most one permissible slot and never overwrites occupancy. Context can restrict an input spelling to a category; slash-separated alternatives may span categories. Output distributions describe one maximum matching, not uniquely identified phonetic assignments.

Expanded mode duplicates the seven double slots as explicit state labels such as b:0/b:1 and r:0/r:1. This gives 3+14+12=29 states. Six fricative aliases are supplied from the existing split operator. No fricative realization is invented for r:1. This is a tagged state expansion, not a bijection between 22 and 29 elements, and not automatic reconstruction of the Arabic, Sabaic or Ugaritic inventories.

Valid/Invalid refers solely to the stipulated structural contract. Duplicate or unrecognized inputs are invalid; counts above 29 trigger the requested dissonance wording as a count-limit flag, not measured acoustic dissonance. Unknown markers retain their positions but do not fill a phonetic slot. A unique reconstruction is proposed only when exactly one slot is absent and every feasible assignment leaves that same slot open. Otherwise all possible missing slots are retained. Structural distance counts uncovered slots plus unassigned known inputs. Harmonic distance remains null without an externally supplied tuning and phoneme-frequency correspondence.

The harmonic-series function returns f_n=n*f_0. The SciPy distance routine returns nearest absolute frequency differences in cents, 1200*abs(log2(f/g)); it does not quotient octaves silently. These functions do not connect the historical phonemes to pitches by themselves. A source-selected list of 22 shruti ratios, reference frequency, correspondence map, equivalence convention and tolerance would be required for a frequency-based restoration test. No equal-22 temperament or purported unique shruti lattice is invented.

The Sefer Yetzirah text explicitly supplies the three/seven/twelve letter partition: https://www.sefaria.org/Sefer_Yetzirah.1-6?no_applink=1 . This supports the textual partition, not a unique assignment to fundamental/octave/fifth, seven diatonic intervals or twelve chromatic pitches. Within-category permutations alone allow 3!*7!*12! different assignments. Category cardinalities therefore cannot prove a historical or acoustically necessary root.
