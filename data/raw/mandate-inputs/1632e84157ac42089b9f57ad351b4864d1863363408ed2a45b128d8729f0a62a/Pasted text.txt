## 3. What the actual mathematical deliverable needs to contain

The most important mathematical object is the set of globally admissible alignments, not a preferred reconstruction produced by a model.

A proposed general form would be:

\\[ \boxed{ \mathcal A_t= \left\\{ a\in\mathcal A: a\text{ satisfies the applicable musical laws and reconstructed constraints at stage }t \right\\} } \\]

Here, \\(\mathcal A\\) is a space of possible global assignments and transformations. The native musical laws and reconstructed constraints determine which assignments remain admissible.

This is a proposed computational formulation for SUNNY, not a previously derived SUN theorem.

It provides a way to express the behavior you have repeatedly requested.

As Jev reconstructs more source relationships, the admissible configurations are constrained. If a discrepancy appears, it must determine whether the discrepancy excludes a configuration, identifies a missing transformation, or requires a previously unrecognized type distinction.

Crucially, an orientation does not have to be uniquely identified for SUNNY to derive meaningful predictions.

If every currently admissible orientation produces the same result at a target locality, the result may already be determined within the reconstructed system.

Formally, if \\(P_a(x)\\) represents the predicted result at locality \\(x\\) under alignment \\(a\\), then:

\\[ \boxed{ \left|\\{P_a(x):a\in\mathcal A_t\\}\right|=1 } \\]

means every surviving alignment agrees on that prediction.

If the resulting set contains multiple predictions, those differences identify candidate targets for the next discriminating investigation.

This allows SUNNY to make progress without inventing uniqueness, assigning arbitrary confidence weights, or repeatedly reopening the entire theory.

It also suggests how Jev should produce rigorous mathematical receipts: each result should identify its assumptions, operators, domain, transformations, derivation, surviving alternatives, and conditions under which it would fail.
