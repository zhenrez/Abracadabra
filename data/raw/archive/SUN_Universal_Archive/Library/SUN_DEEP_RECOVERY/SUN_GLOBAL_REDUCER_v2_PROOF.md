# SUN Global Reducer v2 — Minimality Boundary and Frozen Contracts

## Result

The previous question “are A1–A4 globally minimal?” has two different answers depending on what *minimal* means.

### Pure mathematical encoding
If arbitrary tags are allowed, every deterministic map, constructor, joint relation, and stochastic kernel can be represented inside one sufficiently general typed relation object.

Therefore:

\[
\boxed{\text{pure extensional minimum} = 1}
\]

is possible.

That result is mathematically true but scientifically useless because it erases exactly the distinctions the source record requires us to preserve.

### Semantic-preserving representation
The recovered corpus contains explicit witnesses for at least these distinct operation roles:

- deterministic transition/action;
- deterministic construction/composition;
- joint constitutive incidence;
- stochastic transition.

Those distinctions are source-supported and affect interpretation, composition, arity, and falsification.

Therefore A1–A4 are frozen as **four tagged semantic variants of the representation grammar**.

This is **not** a claim that SUN has four music-native generators.

## Pairwise witness distinctions

### A1 versus A4
Serial transformation, proportional generation, and address mutation are deterministic source claims.

Xenakis Markov transition and IDyOM expectation are probabilistic source claims.

Encoding A1 as a delta-kernel inside A4 is mathematically possible, but doing so removes the evidentiary deterministic/stochastic distinction from the operation type.

### A1 versus A2
A1 acts on an existing typed state/address.

A2 constructs a new configuration/object from parameters or multiple inputs.

A generic function can represent both, but the source distinguishes transition from construction.

### A2 versus A3
Euclidean rhythm/sieve/melakarta-style constructions are procedural constructions.

Hocket/interlocking relations are source-described as joint constitution/complementarity.

A multi-input function can encode both extensionally, but that collapse would erase whether the parts **algorithmically construct** an output or **jointly constitute** the musical object.

### A3 versus A4
Joint constitution is an incidence/constitutive claim, not a probability law.

No probability normalization or stochastic transition is source-supported for the hocket/interlock relations.

## Frozen global composition contract

Composition is partial.

\[
g\circ f
\]

is admissible only when:

1. the output type/carrier of \(f\) is accepted by \(g\);
2. unitization and register are compatible or explicitly adapted;
3. source semantics permit the composition;
4. arity and joint-incidence information survive;
5. path/history is retained where meaningful.

Undefined composition is a scientific result:

\[
\boxed{\text{NONCOMPOSABLE}}
\]

or:

\[
\boxed{\text{UNRESOLVED}}
\]

—not an excuse to invent an adapter.

## Frozen global identity quotient

The default quotient is deliberately trivial:

\[
[x]=\{x\}.
\]

Cross-record sameness must be represented by typed receipts.

Only an actual **IDENTITY** receipt collapses records.

Evaluated equality, observational equivalence, representation equivalence, scoped isomorphism, and generator-family equivalence remain relationships rather than identity.
