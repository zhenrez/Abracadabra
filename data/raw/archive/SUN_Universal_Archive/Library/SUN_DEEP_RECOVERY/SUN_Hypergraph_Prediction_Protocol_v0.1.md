## Governing rule

SUN chooses its structure from music evidence; external templates only organize, project, or test it.

The circular Shem/Yetzirah scaffold is retained as a provisional representation layer. It may be discarded later without changing the empirical or semantic graph.

# II. Canonical hypergraph schema

Node:
v = (id, kind, carrier, class, register, address, unitization, role, state, context, history, source)

Kinds may include:
Entity, Class, Relation, Dimension, Law, Carrier, Boundary, State, Operator, Address, Residual, Representation.

Hyperedge:
e = (id, tails, heads, relation_type, qualifiers, observables, scope, provenance, residual)

N-ary incidence is authoritative. Pairwise projections are visualization only.

Composition receipts must declare domain/codomain, composition, invariants and path-identity status.

Equivalence receipts must distinguish:
evaluated equality; observational equivalence; representation equivalence; isomorphism/conjugacy; generator-family equivalence; identity.

R = 2/3, L = 3/4, O = 1/2
Prediction: RL = LR = O.

P-SUN-02 Reciprocal expansion

Prediction: (3/2)(4/3) = 2.

P-SUN-03 Log-additive representation
d(r)=log2(r)
Prediction: d(ab)=d(a)+d(b), with d(2/3)+d(3/4)=-1.

P-SUN-04 Invariant-preserving redistribution
C_kappa(r1,r2,r3)=(kappa^-1 r1,r2,kappa r3)
Prediction: product(C_kappa(r)) = product(r).

Recovered instance:

P-SUN-05 Equal endpoint does not imply equal path
If E(gamma1)=E(gamma2), only the registered effect is equal.
Distinct internal histories remain distinct unless separately proved equivalent.

P-SUN-06 Relation-first carrier substitution
A cross-domain match requires an explicit adapter declaring:
source carrier; target carrier; preserved relation; operation semantics; unitization; address/register; residual.

P-SUN-07 Local closure may coexist with global displacement

P-SUN-08 Residual is first-class evidence

wrong model; missing variable; context dependence; path/holonomy; measurement error; genuine non-match.

P-SUN-09 Typed count invariance
72_address != 72_entity != 72_configuration != 72_sector
unless an explicit equivalence receipt proves otherwise.

P-SUN-10 Generation before cardinality
A strong match must preserve generation rule + relation type + unitization, not merely a number.

# VI. Circular visualization contract

The circular display is a projection, not ontology.

Default:
- outer ring: 72 address slots
- default grouping: 12 sectors × 6 phase slots
- optional overlay: 3 × 24
- optional nested overlay: 3 × 4 × 6
- radial depth: class/register/level
- node glyph: semantic type
- arrows: transformations/orientation
- hyperedges may span multiple addresses
- dashed edges: external/template correspondences
- residual/non-fit edges remain visible
- empty slots are not automatically missing entities
- occupied slots are not automatically primitive generators

The visualizer must be removable without information loss.
